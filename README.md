# changyy/homebrew-tap

Homebrew casks.

```sh
brew install --cask changyy/tap/uartist
```

| Cask | |
|---|---|
| `uartist` | [UARTist](https://uartist.app/) — a serial console for hardware bring-up (macOS, Apple silicon) |

`Casks/uartist.rb` is updated by each UARTist release; its downloads come
from [changyy/UARTist-release](https://github.com/changyy/UARTist-release).
Problems: [open an issue there](https://github.com/changyy/UARTist-release/issues).
